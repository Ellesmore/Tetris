# 🎮 Тетрис Неон (Tetris Neon)

Современная веб-версия классической игры «Тетрис» с неоновым киберпанк-дизайном, выбором героев, уровнями сложности и адаптивным управлением для мобильных устройств (iOS / Android) и ПК.

---

## ✨ Особенности

- **Выбор героя:**
  - Открытый герой — **«Голо»** с уникальным аватаром.
  - 5 карточек загадочных героев (`???`) — заблокированы с замками для будущих обновлений.
- **3 уровня сложности:**
  - 😌 **Лох** — медленный расслабленный темп (1000 мс / шаг).
  - 😎 **Нормис** — стандартная скорость тетриса (600 мс / шаг).
  - 🔥 **Потужний** — высокая скорость для хардкорных игроков (300 мс / шаг).
- **Классическая механика Tetris:**
  - 7 тетромино (I, O, T, S, Z, J, L) с неоновыми цветами и подсветкой.
  - Призрачная фигура (Ghost piece), проекция падения.
  - Показ следующей фигуры (Next piece).
  - Подсчёт очков, линий и уровней, комбо-множители.
  - Анимация сгорания линий и фон с плавающими неоновыми частицами.
- **Управление:**
  - **Клавиатура (ПК):** Стрелки / WASD (влево/вправо/вниз), Вверх/W (вращение), Пробел (хард-дроп), Esc/P (пауза).
  - **Сенсорный экран (Мобильные / iOS Safari):** Свайпы и экранные кнопки с автоповтором при удержании.
  - Полная поддержка Safe Area Inset для iPhone с вырезами / Dynamic Island.

## 🚀 Деплой на Vercel

Проект собран как **чистый статический веб-сайт** (Static Site), что обеспечивает максимальную скорость работы через глобальную сеть Vercel Edge CDN без задержек и холодных стартов.

### Настройка автоматического деплоя из GitHub:

1. Перейдите в [Vercel Dashboard](https://vercel.com/dashboard).
2. Нажмите **Add New...** → **Project**.
3. В списке репозиториев найдите **`Ellesmore/Tetris`** и нажмите **Import**.
4. В параметре **Framework Preset** выберите **Other** (по умолчанию определится автоматически).
5. Нажмите **Deploy**.

После этого **каждый push в ветку `main`** на GitHub будет **автоматически** обновлять сайт на Vercel за несколько секунд!

## 💻 Локальный запуск

Так как проект полностью статический, его можно открыть:
- Запустив локальный сервер:
  ```bash
  npx serve .
  ```
  или с помощью Python:
  ```bash
  python -m http.server 3000
  ```
- Либо запустить имеющийся скрипт:
  ```bash
  node server.js
  ```
  и открыть в браузере `http://localhost:3000`.
